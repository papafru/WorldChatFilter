# World Chat Filter v1.0.0

**Keep the conversation. Filter the noise.**

A World-only spam filter for WoW clients using the Vanilla 1.12 API, including OctoWoW 1.18.

Open settings with `/wcf`; open statistics with `/wcf stats`.

For detailed installation, commands, configuration, privacy, and known limitations, visit:
https://github.com/papafru/WorldChatFilter
