# World Chat Filter — In-game screenshots

Real screenshots captured in the **OctoWoW 1.18 client**. These images illustrate the World Chat Filter user interface. The live values shown in statistics and status are examples from one character's session, not fixed results.

## World Chat Color settings and custom color picker

The compact Blizzard-style settings menu contains filter categories, detection sensitivity, statistics and World Chat Color. The native color picker lets players adjust the World channel tint while leaving Trade and other channels unaffected.

![Main settings, World Chat Color submenu and RGB color picker](screenshots/color-picker-settings-overview.webp)

## Statistics panel (v1.1)

Session and all-time hidden-message counts for World chat: Trade, LFG, Guild, Services, Repeated Messages, and Custom. Reset All includes an in-window confirmation.

![World Chat Filter v1.1 — Statistics](https://github.com/user-attachments/assets/add029db-3b51-4314-ac73-b3b95dc4d2a2)

## Custom Filters panel (v1.1)

Manage personal Blocked Players and Words & Phrases with a consistent Dark Arcane Blizzard interface, without using WoW's global ignore list.

![World Chat Filter v1.1 — Custom Filters](https://github.com/user-attachments/assets/fe01b6ef-b251-4957-bba9-f9e921b7f0db)

## Help / Commands panel (v1.1)

Browse the real supported slash commands on General, Custom Filters and Tools tabs by typing `/wcf help`.

![World Chat Filter v1.1 — Help and Commands](https://github.com/user-attachments/assets/47ffc44a-dbf4-45e6-8d36-74155da7e2c3)

## Information menu

Quick access to filtering status, active sensitivity, selected World tint, session hidden count, and the **Shift + drag** minimap-button movement instruction.

![Information submenu showing enabled filter and current settings](screenshots/information-menu.webp)

## Custom World Chat Color picker

Use the four color presets or select a custom RGB tint using WoW's built-in Color Picker. **Dusty Gold** is the default preset; the displayed color affects only new World messages.

![World Chat Color submenu and native RGB picker](screenshots/color-picker-custom.webp)

## Detection sensitivity

Three selectable modes: **Careful** minimizes false positives, **Balanced** is recommended for most players, and **Aggressive** attempts to hide more advertising.

![Careful, Balanced and Aggressive detection settings](screenshots/detection-sensitivity.webp)
